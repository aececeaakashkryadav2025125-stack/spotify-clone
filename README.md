# 🎵 Spotify Clone – Full Stack Music Streaming App

A fully responsive Spotify-inspired music streaming web application built using the MERN stack. The application allows users to browse songs, manage playlists, stream music, and experience a modern music player UI similar to Spotify.

---

## 🚀 Live Demo

🔗 Live Project: https://spotify-clone-chi-lilac.vercel.app/

---

## 📌 Features

- 🎧 Music Streaming Interface
- 🔍 Search Songs & Playlists
- 📂 Dynamic Playlist Management
- ⏯️ Music Player Controls
- 👤 User Authentication & Authorization
- 📱 Fully Responsive Design
- ⚡ Optimized Performance
- 🌐 REST API Integration
- ☁️ Full Stack Deployment
